# 🎓 우리 아이 감정 조절 마스터 시스템: 모듈 커리큘럼 맵 (V1)

## 상품명: 우리 아이 감정 조절 마스터 시스템: 놀이 기반 3단계 커리큘럼
### 타겟 페인 포인트 해결 구조: 이론(불안) $\rightarrow$ 원리 이해(전문성) $\rightarrow$ 실습 도구(해결책)

**[FREE] Level 1. 기본 입문:** 문제 인식 및 동기 부여 (Pain Point Acknowledge)
*   Module 1.1: 감정의 비밀 지도 - 우리 아이 기질과 발달 단계별 이해
*   Module 1.2: 놀이와 감정 조절의 과학적 연결고리

**[STANDARD] Level 2. 기초 시스템 구축:** 원리와 방법론 학습 (Solution Concept)
*   Module 2.1: 3단계 커리큘럼 이론 - 인식 $\rightarrow$ 안정화 $\rightarrow$ 대처 시나리오 설계 (Growth Flow 기반)
*   Module 2.2: 부모의 역할 가이드 및 감정 체크리스트 제공 (실용성 확보)

**[PREMIUM] Level 3. 완성 로드맵:** 즉시 적용 가능한 실습 교재와 개인화 시스템 (Actionable Tool Kit)
*   Module 3.1: [필수] 상황별 놀이 활동 매뉴얼 및 스크립트 (5대 위기 상황 대응)
*   Module 3.2: 우리 가족 맞춤형 감정 진단 테스트 및 분석 리포트 제공
*   Module 3.3: 온라인 코칭 세션 참여 기회 (최상급 경험 가치 부여)
