# 🎥 [최종 확정] 유튜브 영상 스크립트 (60초)
## 주제: 우리 아이 화난 건 왜일까요? 전문가가 알려주는 감정 조절 놀이 3가지
## 타겟: 5~8세 자녀를 둔 학부모 (불안 해소 니즈 보유)
## 목표 시간: 약 60초
## 브랜드 톤: 친근하지만 전문적인 공감형 (Deep Teal & Soft Coral 활용)

---

### 📜 스크립트 개요 및 제작 가이드라인

*   **총 분량:** 58~62초 사이를 목표로 편집 속도에 따라 조절합니다.
*   **핵심 구조:** Growth Flow (Pain Point → 문제 상황 시각화 → 해결책 제시/놀이 스킬 → CTA)
*   **톤앤매너:** 초반(Deep Teal)은 공감과 불안 자극, 중후반(Soft Coral)은 따뜻한 해결책 제시, 마지막(Deep Teal)은 전문적 확신을 전달합니다.

---

| Time Code | Visual Description (화면 연출 지시) | Narration / Dialogue (나레이션/대사) | 비고 / 감성 포인트 |
| :---: | :--- | :--- | :--- |

(신뢰와 권위 구축). |
