CEO님의 지시와 Writer 에이전트가 수집한 설문 데이터(학부모의 교육적 불안 및 WTP)를 바탕으로, 소셜 네트워크에 게시할 시각 자료(썸네일 또는 인포그래픽) 디자인 브리프와 3가지 핵심 비주얼 컨셉을 제안합니다.

---

## 📄 디자인 브리프: 설문 홍보 비주얼 시스템

이 비주얼은 학부모의 **'교육적 불안 해소'**라는 심리적 니즈에 공감하며, Hz컴퍼니가 제공하는 데이터 기반의 해결책을 신뢰감 있게 제시하는 것을 목표로 합니다.

### 1. 핵심 메시지 (Core Message)
"우리 아이에게 꼭 맞는 학습, 불안함을 기회로 바꾸는 시작점."

### 2. 디자인 목표 (Design Goal)
*   **신뢰 구축 (Trust):** 학부모가 정보를 신뢰하고 참여하도록 안정적이고 전문적인 느낌을 전달합니다.
*   **공감 유도 (Empathy):** 학부모가 자신의 고민이 이해받고 있다는 느낌을 받도록 따뜻한 톤을 사용합니다.
*   **행동 촉구 (Action):** 설문에 대한 참여를 쉽고 명확하게 유도하여 클릭을 발생시킵니다.

### 3. 비주얼 시스템 제안 (Visual System Proposal)

| 요소 | 제안 내용 | 상세 설명 및 이유 |
| :--- | :--- | :--- |
| **메인 컬러** | **Primary:** `#4A90E2` (신뢰의 블루, 안정감) | 학부모가 가장 선호하는 신뢰감을 주는 색상입니다. |
| | **Secondary:** `#F5A623` (따뜻한 오렌지/골드, 활력) | 불안함을 해소하고 긍정적인 기회(솔루션)를 제시하여 따뜻함과 희망을 더합니다. |
| | **Accent:** `#7ED321` (밝은 그린, 성장/성취) | 학습의 성장과 긍정적인 변화를 상징하며 시각적 활력을 제공합니다. |
| **타이포그래피** | **제목/헤드라인:** Pretendard Bold (또는 Noto Sans KR Bold) | 가독성이 높고 모던하면서도 친근함을 유지합니다. |
| | **본문/데이터:** Pretendard Regular / Noto Sans KR Regular | 정보 전달의 명확성을 최우선으로 합니다. |
| **레이아웃 컨셉** | **삼분할 구조 (Rule of Thirds)** | 좌측(문제/불안) - 중앙(질문/중심 메시지) - 우측(해결책/CTA)의 흐름을 명확히 제시합니다. |

## 🖼️ 썸네일 컨셉 3안 비교 정리

제안된 브리프를 바탕으로, 세 가지 다른 접근 방식을 가진 썸네일 컨셉을 제안합니다. (모두 가로형 비율 권장: 16:9 또는 4:3)

### 컨셉 1: 공감 기반의 '불안 해소' 강조 (Empathy Focus)

*   **컨셉 명:** 불안의 그림자를 밝히는 빛
*   **핵심 시각 요소:** 어두운 배경(옅은 네이비 또는 그레이) 위에 아이가 책을 보며 약간 고민하는 듯한 실루엣. 이 실루엣 위로 따뜻하고 밝은 노란색/주황색 빛이 비쳐 들어오면서, 질문 항목들이 깔끔하게 배치됩니다.
*   **텍스트 강조:** "우리 아이 학습, 혹시 불안하신가요?" (큰 폰트) + 작은 글씨로 설문 참여 유도 문구.
*   **컬러 사용:** 메인 블루(#4A90E2)와 따뜻한 오렌지(#F5A623)의 대비를 통해 '어둠(불안)'에서 '빛(해결책)'으로 전환되는 느낌을 강조합니다.
*   **적합한 데이터 유형:** Pain Point 심층 분석 섹션 (B, C).

### 컨셉 2: 솔루션 기반의 '기회 포착' 강조 (Solution Focus)

*   **컨셉 명:** 데이터로 찾는 맞춤 학습 로드맵
*   **핵심 시각 요소:** 깔끔한 인포그래픽 스타일. 중앙에 큰 아이콘(돋보기 또는 나침반)을 배치하고, 그 주변으로 A, B, C 등의 선택지가 마치 지도처럼 연결되어 있습니다. 각 선택지 옆에는 작은 체크 표시나 성장 그래프 아이콘이 붙어있습니다.
*   **텍스트 강조:** "학부모님의 선택이 만드는 맞춤 학습 로드맵" (메인 헤드라인) + 핵심 질문 3~4개를 목록화하여 제시.
*   **컬러 사용:** 그린(#7ED321)을 메인 액션 색상으로 사용하여 '성장'과 '긍정적 변화'를 시각적으로 강조합니다.
*   **적합한 데이터 유형:** 가치 검증 및 WTP 측정 섹션 (C).

### 컨셉 3: 직접적인 참여 유도형 (Action Focus)

*   **컨셉 명:** 5분 만에 끝내는 학습 니즈 진단 테스트
*   **핵심 시각 요소:** 화면 중앙에 설문지 일부(가장 흥미로운 질문 1~2개)를 팝업 형태로 배치하고, 그 주변을 화살표로 감싸며 "지금 참여하세요!"라는 CTA를 강력하게 제시합니다. 배경은 깨끗한 흰색 또는 아주 연한 파스텔톤입니다.
*   **텍스트 강조:** "학부모님, 딱 5분만 투자해 주세요." (시간 절약의 가치 강조) + 설문 링크 버튼을 가장 눈에 띄게 만듭니다.
*   **컬러 사용:** 화이트 배경 위에서 블루(#4A90E2)와 오렌지(#F5A623)를 포인트 색상으로 사용하여 시선 집중도를 극대화합니다.
*   **적합한 데이터 유형:** 도입부 (Ice Breaking & Needs Assessment - A).
