### 📈 학부모 대상 '불안 해소' SEO 키워드 및 페인 포인트 데이터 리스트 (Ver. 1.0)

#### I. 검색 의도 기반 키워드 분류 (Search Keywords)

| 카테고리 | 유형 | 핵심 키워드 예시 (검색량 높음 순 예상) | 콘텐츠 활용 방안 |
| :--- | :--- | :--- | :--- |
| **A. 문제 인식/불안 (Pain Point)** | Long-Tail / 질문형 | "5살 아이 학습 불안 해소 방법", "초등 저학년 흥미 잃었을 때 대처법", "아이 스스로 배우게 하는 법" | 메인 페이지 Pain Point 섹션, 블로그 포스팅 주제. 공감 유도 카피 작성. |
| **B. 해결책 탐색 (Solution Seeking)** | Mid-Tail / 정보성 | "어린이 인지 능력 향상 놀이", "만 5세 발달 단계별 교육", "전집보다 좋은 학습법" | Solution Section에 구체적인 프로그램 근거 제시. '무엇을 할 수 있는지' 보여주는 기능 나열. |
| **C. 제품 비교/구매 (Purchase Intent)** | Short-Tail / 상업성 | "어린이 인지 교육 프로그램 추천", "학습 콘텐츠 비교", "[경쟁사 이름] 대안" | Pricing Section 최상단에 배치. 즉각적인 구매 동기를 유발하는 문구 사용. |
| **D. 감정적 검색 (Emotional)** | Long-Tail / 경험 공유 | "아이와 놀면서 배우는 방법", "학습 스트레스 줄이는 부모 팁", "엄마가 불안할 때 필요한 것" | Trust Section에 적용하여 '부모의 심리'까지 케어한다는 메시지 전달. |

#### II. 페인 포인트 기반 카피라이팅 질문 (Pain Points & Questions)

SEO는 키워드뿐만 아니라, 사용자가 검색창에 직접 입력하는 **질문 형태**가 매우 중요합니다. 랜딩 페이지와 콘텐츠 전반에 이 질문들을 녹여내야 합니다.

1.  **학습 동기 관련:** "공부해야 하는데 아이가 흥미를 느끼지 못해요." (→ 놀이 기반 학습의 필요성 강조)
2.  **발달 단계 불확실성:** "지금 우리 아이 발달 수준이 적절한 걸까요? 뭘부터 가르쳐야 할지 모르겠어요." (→ 체계적인 로드맵/진단 기능 강조)
3.  **학습 스트레스:** "공부 자체가 숙제가 되어서 엄마와 아빠가 힘들어졌어요." (→ '안심'과 '즐거움'을 최우선 가치로 제시하며 심리적 접근)

#### III. 핵심 콘텐츠 기둥 (Pillars for Content Strategy)

랜딩 페이지의 기능 설명을 넘어, 블로그나 유튜브 등에서 지속적으로 생산해야 할 3대 주제(기둥)입니다. 이 주제들이 곧 검색 트래픽을 끌어오는 역할을 합니다.

1.  **[ Pillar 1: 놀이와 학습의 접점 ]**: 교육적 활동을 '재미있는 경험'으로 포장하는 방법론 제시. (예: 보드게임, 미술활동과 연계한 인지 능력 향상)
2.  **[ Pillar 2: 부모 코칭 가이드 ]**: 학부모가 불안감을 느끼는 지점을 해소해주는 '멘탈 관리법' 제공. (Hz컴퍼니를 사용하는 것이 단순히 학습이 아니라, *양육의 자신감*을 얻는 것임을 강조)
3.  **[ Pillar 3: 연령별/발달 단계별 가이드 ]**: 명확하고 구체적인 정보 제공으로 '전문성' 어필. (예: 만 4세 시기 인지 발달 체크리스트, 초등학교 입학 전 필수 학습 습관)
